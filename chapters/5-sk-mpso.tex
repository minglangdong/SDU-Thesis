\chapter{基于对称密钥的通用多方隐私集合运算框架}
\echapter{Generic Multi-Party Private Set Operations Framework Based on Symmetric-Key Operations}

\section{引言}
\esection{Introduction}

在第三章和第四章中，本文重点研究了多方隐私集合求并（Multi-party Private Set Union, MPSU）这一特定功能，并分别基于对称密钥技术和公钥密码技术提出了满足标准半诚实安全的高效协议。然而，在实际应用中，多方隐私集合运算（MPSO）的需求远不止于单一的交集或并集计算。现实的数据协作场景通常需要对交、并、差等基本运算进行组合，从而形成更为复杂的集合公式计算。以下三个典型应用场景生动地说明了现实世界的数据共享与协作分析对集合复合公式计算的的迫切需求：

\begin{itemize}
    \item \textbf{公共卫生监测与决策支持.}在传染病防控中，卫生部门需精准识别“已接种特定疫苗但仍被确诊感染”的人群。这要求首先联合多家疾控中心的接种名单计算并集 $\bigcup V_i$，随后与各医疗机构持有的确诊名单的并集 $\bigcup D_i$ 计算交集 $(\bigcup V_i) \cap (\bigcup D_i)$，其中 $V_i$ 与 $D_i$ 分别代表第 $i$ 家疾控中心持有的接种名单与第 $i$ 家医疗机构持有的确诊名单。此类分析对于评估疫苗有效性及制定后续防疫政策至关重要。

    \item \textbf{联合金融风控与反欺诈.} 在跨机构反欺诈场景中，银行联盟希望构建一个覆盖全行业的风险黑名单数据库，但为了保护高净值客户隐私，必须确保计算结果中排除了各行各自的白名单客户。该需求对应于计算复合公式 $(\bigcup B_i) \setminus (\bigcup W_i)$，其中 $B_i$ 与 $W_i$ 分别代表第 $i$ 个银行持有的黑名单与白名单。

    \item \textbf{广告归因与转化效果评估.} 在广告归因分析中，广告商往往需要进行多维度的转化分析。例如，为衡量全渠道投放广告对线下购买的综合贡献，需计算所有投放平台浏览受众 $V_i$ 的并集与购买列表 $P$ 的交集 $(\bigcup V_i) \cap P$；为评估某新合作平台的独家拉新能力，这需要计算购买列表与新平台浏览该广告的受众的交集，并剔除所有其他平台的浏览受众的并集，即计算 $(P \cap V_{\text{new}}) \setminus (\bigcup V_{\text{others}})$。
\end{itemize}

针对上述需求中集合复合公式的安全计算问题，现有解决思路大体可分为两类：
第一类思路是针对特定应用场景设计具体的 MPSO 协议。该类方法通常围绕特定功能进行深度优化，因此在目标场景下能够获得较高的执行效率。然而，该路线在实际应用中仍面临明显局限。一方面，学术界对复杂集合运算场景的关注相对有限，现有研究主要集中在交集与并集等基础且结构较为简单的功能上，导致许多实际应用需求（如前述三个典型应用场景）至今仍缺乏高效且可落地的具体解决方案。另一方面，由于不同协议往往基于异构的密码学技术路线独立设计，各协议之间缺乏统一的功能抽象与结构框架，整体表现出较差的灵活性与可扩展性。当应用需求发生变化时，系统往往需要重新设计或替换底层协议，从而显著增加系统部署、集成与运维成本，难以满足现实环境中对敏捷部署与长期演进的需求；
第二类思路是构建通用的 MPSO 框架，实现计算任意集合公式的通用 MPSO 功能。这一直是MPSO领域的重要研究目标，但实现该目标面临显著的技术挑战。早在该领域发展的早期，Kissner 与 Song 在其经典工作中 \cite{KS-CRYPTO-2005} 即尝试解决这一问题。然而，该框架受限于其采用的集合公式表示方式 —— 将目标公式表示为交集、并集及元素规约（element reduction）操作的组合，仅能表达由交运算与并运算构成的集合表达式，无法支持差集运算。因此，该方法难以覆盖许多实际应用需求（例如前述应用场景二与三中的相关实例）。此外，该框架高度依赖加法同态加密，计算成本极高，其效率根本无法满足现实世界的应用需求，因此仅具有理论价值。此后的二十年间，关于 MPSO 框架的研究进展十分有限，仅有Blanton 和 Aguiar 提出的一项方案 \cite{BA-ASIACCS-2012} 基于通用 MPC 技术实现了完整的通用 MPSO 功能。尽管该方法在表达能力上具有完备性，但其依赖电路实现集合运算，导致计算和通信开销高。在现实规模数据场景下，其性能开销难以接受，从而限制了其在实际系统中的部署与应用。

综上所述，现有两类技术路线分别在灵活性与效率之间存在明显权衡：具体的 MPSO 协议效率较高但功能单一，而通用的 MPSO 框架表达能力完备却难以满足实际性能需求。这一矛盾表明，设计一种兼具通用性与高效率的任意集合公式计算框架，仍然是当前MPSO研究中亟待解决的关键问题。本章致力于解决这一长期悬而未决的开放性问题：
\begin{center}
\emph{能否在标准半诚实模型下，构建出同时实现通用 MPSO 功能并且具备实际可用效率的 MPSO 框架？}
\end{center}

本章围绕上述问题展开研究，从表示方法、密码学原语与系统框架三个层面提出了一套新的技术体系：

\begin{enumerate}
    \item \textbf{表示层.} 本章引入了一种全新的任意集合公式表示方式 —— 规范集合谓词公式（Canonical Set Predicate Formula, CSPF）。该表示方式将目标集合公式表示为一类由原子集合谓词（形如 $x \in X_i$ 或 $x \notin X_i$）构成的析取范式，其中每个子公式满足特定的结构，子公式共同表示了目标集合的一个划分，从而将复杂的集合公式计算问题转化为若干个相互独立的子公式计算问题，为并行化与模块化计算提供基础。
    \item \textbf{原语层.} 本章提出一种可组合的新型密码学原语 —— 谓词零分享（Predicative Zero-Sharing），并在集合运算场景下给出其特化实例 —— 成员零分享（Membership Zero-Sharing）。该原语的核心功能是将指定逻辑谓词在各参与方输入上的真值“不经意地”编码为秘密分享的形式，并支持基于逻辑运算的组合计算。为实现成员零分享的高效构造，本文首先提出谓词零分享的松弛版本（Relaxed Predicative Zero-Sharing）的定义，并设计了相应的组合技术与转化技术，从而给出一种自底向上的高效构造范式：从关联于原子命题（或其否定）的松弛谓词零分享出发，逐步构造关联于任意复杂谓词公式、满足标准半诚实安全的谓词零分享协议。基于该范式，本章通过分别针对成员原子集合谓词 $x \in X_i$ 和非成员原子集合谓词 $x \notin X_i$ 给出了成员零分享的松弛版本（Relaxed Membership Zero-Sharing）的高效实例化，最终实现了关联于任意集合谓词公式的标准安全成员零分享协议。该协议是本文提出的 MPSO 统一框架的核心底层组件，其高度的可组合性是本章提出的 MPSO 框架能够支持任意集合公式的核心依赖。
    \item \textbf{框架层.} 基于 CSPF 表示法与成员零分享原语，并结合多方秘密分享洗牌协议，本章构建了支持任意集合公式计算的 MPSO 统一框架。该框架的基本思想是将输入集合中所有满足目标集合公式的元素转化为各方持有的秘密分享序列，这一思想赋予了该框架极强的扩展性，使得其能进一步实现任意集合公式结果求势（MPSO-card）及基于电路的通用MPSO（Circuit-MPSO）功能，从而满足更复杂的数据分析需求。
\end{enumerate}

本章后续内容的安排如下：第 5.2 节提出规范集合谓词公式（CSPF）的定义，并证明任意集合公式转化为 CSPF 的等价性定理；第 5.3 节详细阐述谓词零分享原语的安全性定义、松弛定义以及组合与转化范式；第 5.4 节介绍成员零分享协议的实例化及关联于任意集合谓词公式的标准安全成员零分享协议的高效构造方案；第 5.5 节给出 MPSO 统一框架的完整执行流程及安全性证明、复杂度分析；最后，第 5.6 节对本章内容进行总结。

\section{集合公式的谓词公式表示}~\label{sec:predicate_formula}
\esection{Predicate Formula Representation of Set Formulas}

本节给出一种用于表示任意集合公式的统一形式 —— 规范集合谓词公式（Canonical Set Predicate Formula, CSPF）。该表示方式是本章统一框架的表示层基础，通过把目标集合公式表示为若干个子公式的析取，将其对应的结果集合 $Y$ 划分为若干个相互不相交的子集合 $\{Y_1, \cdots, Y_s\}$，并且满足每个 $Y_i$ 一定是某个输入集合的子集，从而为后续 MPSO 框架的设计和其中基于成员零分享的模块化计算提供结构支持。下面通过定义一系列概念来精确地刻画这些结构性质，从而形式化规范集合谓词公式的定义。

\subsection{可构造集合与集合谓词公式}

设 $X_1,\cdots,X_m$ 为 $m$ 个参与方的私有集合。我们首先形式化由这些集合通过任意集合公式的计算所能得到的结果集合，统称为 $X_1, \cdots, X_m$ 上的可构造集合（constructible set）。

\begin{definition}[可构造集合]
给定集合 $X_1,\cdots,X_m$，若集合 $Y$ 可由 $X_1, \dots, X_m$ 经过有限次集合运算（包括求交、并、差集运算）导出，则称 $Y$ 为 $X_1, \cdots, X_m$ 上的可构造集合。\footnote{在上下文语境明确时，可简称为可构造集合。}
\end{definition}

特别地，若对于某个 $1 \le i \le m$，可构造集合 $Y$ 满足 $Y \subseteq X_i$，则称其为（$X_1, \cdots, X_m$ 上的）$X_i$-局部的可构造集合（$X_i$-local constructible set）。

为了刻画集合元素级别的成员判定关系，下面引入集合谓词公式的概念。

\begin{definition}[集合谓词公式]
若谓词公式 $\varphi(x,X_1,\cdots,X_m)$ 由原子命题由形如 $M(x, X_i): x \in X_i$（$M$ 称为集合成员谓词）的原子命题组成，则称其为集合谓词公式。
\end{definition}

可构造集合和集合谓词公式之间存在如下对应关系。

\begin{theorem}\label{theorem:set1}
设 $Y$ 为 $X_1,\cdots,X_m$ 上的可构造集合，则存在一个集合谓词公式 $\varphi(x, X_1, \cdots, X_m)$，使得对于任意 $x$，满足：
$$x \in Y \iff \varphi(x, X_1, \cdots, X_m) = 1.$$
此时，称集合谓词公式 $\varphi$ 表示可构造集合 $Y$，或称 $\varphi$ 为 $Y$ 的集合谓词公式表示。
\end{theorem}

\begin{proof}
下面通过对集合运算的次数进行数学归纳法构造 $\varphi$。
\begin{itemize}
    \item \textbf{基础情况.} 若存在某个 $i \in \{1, \cdots, m\}$ 使得 $Y = X_i$，显然 $\varphi(x, X_1, \cdots, X_m) = M(x, X_i): x \in X_i$。
    \item \textbf{归纳假设.} 假设对于由 $X_1, \dots, X_m$ 出发经过 $k$ 次集合运算得到的任意集合 $A$ 和 $B$，均存在集合谓词公式 $\varphi_A$ 和 $\varphi_B$，使得：
    $$x \in A \iff \varphi_A(x, X_1, \cdots, X_m) = 1, \quad x \in B \iff \varphi_B(x, X_1, \cdots, X_m) = 1.$$
    \item \textbf{归纳步骤.} 考虑由 $A$ 和 $B$ 经过一次额外的集合运算得到的集合 $Y$（即从 $X_1, \cdots, X_m$ 出发需要 $k+1$ 次集合运算得到 $Y$），根据集合运算的类型构造 $\varphi$ 如下：
    \begin{enumerate}
        \item \textbf{并集.} 若 $Y = A \cup B$，则 $\varphi(x, X_1, \cdots, X_m) = \varphi_A(x, X_1, \cdots, X_m) \lor \varphi_B(x, X_1, \cdots, X_m)$。
        \item \textbf{交集.} 若 $Y = A \cap B$，则 $\varphi(x, X_1, \cdots, X_m) = \varphi_A(x, X_1, \cdots, X_m) \land \varphi_B(x, X_1, \cdots, X_m)$。
        \item \textbf{差集.} 若 $Y = A \setminus B$，则 $\varphi(x, X_1, \cdots, X_m) = \varphi_A(x, X_1, \cdots, X_m) \land \neg \varphi_B(x, X_1, \cdots, X_m)$。
    \end{enumerate}
\end{itemize}
以此类推，即可为任意可构造集合 $Y$ 构造相应的集合谓词公式 $\varphi$。证毕。
\end{proof}

上述定理表明，任意集合公式计的算问题均可转化为元素级的集合谓词逻辑判定问题。但是为了适配后续 MPSO 框架的设计，我们需要该表示具有特定的结构特性。下面先定义集合谓词公式相对于某一输入集合的“局部性”，这一性质使得该公式在输入集合上的计算结果可通过执行一次成员零分享协议的实例来实现秘密分享。


\begin{definition}[局部性]\label{def:local}
若集合谓词公式 $\varphi(x, X_1, \cdots, X_m)$ 可以写成如下形式：
$$\varphi(x, X_1, \cdots, X_m) = (x \in X_i) \land \psi(x, X_1, \cdots, X_{i-1}, X_{i+1}, \cdots, X_m),$$
其中 $\psi(x, X_1, \cdots, X_{i-1}, X_{i+1}, \cdots, X_m)$ 不包含关于 $X_i$ 的原子命题，则称 $\varphi$ 相对于 $X_i$ 是局部的（local to $X_i$）或称其为 $X_i$-局部的（$X_i$-local）集合谓词公式，同时，称 $\psi$ 为 $\varphi$ 的 $X_i$-局部剩余公式（residual formula）。
\end{definition}

\begin{corollary}
若可构造集合 $Y$ 的集合谓词公式表示为 $X_i$-局部的集合谓词公式，则 $Y$ 一定是 $X_i$-局部的可构造集合。
\end{corollary}

\subsection{规范集合谓词公式表示}

在上述概念的基础上，下面正式给出规范集合谓词公式的定义。

\begin{definition}[规范集合谓词公式（CSPF）]\label{def:cspf}
设集合谓词公式 $\psi(x, X_1, \cdots, X_m)$ 为一个或多个子公式的析取\footnote{单个子公式的析取即为其自身。}，记作 $\psi = Q_1 \lor \cdots \lor Q_s (s \ge 1)$。若 $\psi$ 满足以下两个条件：
\begin{enumerate}
\item \textbf{局部性：} 每个子公式 $Q_i$ ($1 \leq i \leq s$)  相对于某个输入集合 $X_j$ ($1 \leq j \leq m$) 是局部的；
\item \textbf{划分性：} 令 $Y$ 为 $\psi$ 所表示的可构造集合，$Y_i$ 为子公式 $Q_i$ 所表示的可构造集合，$\{Y_1,\cdots,Y_s\}$ 构成$Y$ 的一个划分，即 $$Y_i \cap Y_k = \emptyset \ (i \ne k), \quad \bigcup_{i=1}^s Y_i = Y;$$
\end{enumerate}
则称 $\psi(x, X_1, \cdots, X_m)$ 为一个（在 $X_1, \cdots, X_m$ 上的）规范集合谓词公式（CSPF）。
\end{definition}

以上 CSPF 的结构保证了其表示的目标集合可划分为若干个互不相交的局部子集，从而可在 MPSO 框架下分别计算。下面的定理证明了这种表示法的普适性。

\begin{theorem}\label{theorem:set2}
设 $Y$ 为 $X_1,\cdots,X_m$ 上的可构造集合，则存在一个 CSPF $\psi(x, X_1, \cdots, X_m)$，使得对于任意 $x$，满足：
$$x \in Y \iff \psi(x, X_1, \cdots, X_m) = 1。$$
\end{theorem}

\begin{proof}
根据定理 \ref{theorem:set1}，$Y$ 可以表示为一个集合谓词公式。因为任何集合谓词公式都可以转化为析取范式（Disjunctive Normal Form, DNF），$Y$ 可以表示为一个 DNF 公式：
$$\varphi(x, X_1, \cdots, X_m) = C_1 \lor \cdots \lor C_n$$
其中每个 $C_i$ ($1 \le i \le n$) 都是一个合取项。

首先，利用反证法证明 $\varphi$ 可以转化为另一个包含 $s$ 个合取项 ($s > n$) 的 DNF 公式 $\psi$，使得每个 $C_i$ ($1 \le i \le s$) 至少包含一个形如 $x \in X_j$ 的原子命题，即 $C_i$ 可以写成 $C_i = (x \in X_j) \land D_i$ 的形式：
假设存在一个合取项 $C_i$ 不包含任何形如 $x \in X_j$ 的原子命题，即 $C_i$ 是若干形如 $x \notin X_j$ 的原子命题的合取。考虑以下两种情况：
\begin{itemize}
    \item \textbf{情况 1：} $C_i = (x \notin X_{i_1}) \land \cdots \land (x \notin X_{i_{t}})$，其中 $t < m$。由于 $C_i$ 是 $\varphi$ 的一个合取项，其对应的集合 $Y'_i$ 是可构造集合 $Y$ 的子集，且 $Y'_i$ 本身也是一个可构造集合。因此，可以通过如下方式扩充 $C_i$：
    \begin{align*}
    C_i &= C_i \land \big((x \in X_1) \lor \cdots \lor (x \in X_m)\big) = (C_i \land (x \in X_1)) \lor \cdots \lor (C_i \land (x \in X_m)).
    \end{align*}
    对于任何同时包含 $x \in X_{i_d}$ 及其否定 $x \notin X_{i_d}$ ($1 \leq d \leq t$) 的合取项，其求值结果恒为 0，可以舍弃。剩余的公式为：
    \begin{align*}
    C_i = (C_i \land (x \in X_{j_1})) \lor \cdots \lor (C_i \land (x \in X_{j_{m-t}})) = C_{i,1} \lor \cdots \lor C_{i,m-t}.
    \end{align*}
    这将每个 $C_i$ 拆分为 $m-t$ 个合取项，其中每个合取项至少包含一个形如 $x \in X_j$ 的原子命题。将每个 $C_i$ 替换为上述等式，可得到新的 DNF 公式：
    $$\psi(x, X_1, \cdots, X_m) = C_1 \lor \cdots \lor C_s,$$
    其中每个 $C_i$ ($1 \le i \le s$) 表示某个 $X_j$-局部的可构造集合，但此时 $C_i$ 尚未满足 $X_j$-局部的集合谓词公式的定义，因为 $D_i$ 中可能仍包含与 $X_j$ 相关的原子命题。
    \item \textbf{情况 2：} $C_i = (x \notin X_1) \land \cdots \land (x \notin X_m)$。这与 $C_i$ 表示的集合 $Y_i$ 可由 $X_1, \cdots, X_m$ 通过集合运算得到相矛盾（即元素不可能不属于任何输入集合，却在可构造集合中），因此这种情况不成立。
\end{itemize}

接下来，将新的 DNF 公式 $\psi$ 转化为表示互不相交集合 $\{Y_1, \cdots, Y_s\}$ 的子公式析取形式：由于 $\psi$ 的析取形式蕴含 $Y_1 \cup \cdots \cup Y_s = Y$，若能证明不相交性，则证明了 $\{Y_1, \cdots, Y_s\}$ 构成 $Y$ 的一个划分。
令 $\psi_1(x, X_1, \cdots, X_m) = C_2 \lor \cdots \lor C_s$，则有 $\psi(x, X_1, \cdots, X_m) = C_1 \lor \psi_1(x, X_1, \cdots, X_m)$。我们将此式扩充为 $C_1 \lor ((C_1 \land \neg C_1) \lor \psi_1(x, X_1, \cdots, X_m))$，展开得到 $C_1 \lor (C_1 \land \psi_1(x, X_1, \cdots, X_m)) \lor (\neg C_1 \land \psi_1(x, X_1, \cdots, X_m))$。鉴于 $C_1 \land \psi_1 = 1$ 必然要求 $C_1 = 1$，故 $C_1 \lor (C_1 \land \psi_1) = C_1$，因此：
$$\psi(x, X_1, \cdots, X_m) = C_1 \lor (\neg C_1 \land \psi_1(x, X_1, \cdots, X_m)).$$
对所有的 $C_i$ ($1 \le i \le s$) 重复此过程，我们得到：
$$\psi(x, X_1, \cdots, X_m) = C_1 \lor (\neg C_1 \land C_2) \lor \cdots \lor (\neg C_1 \land \neg C_2 \land \cdots \land \neg C_{s-1} \land C_s).$$
记作 $\psi(x, X_1, \cdots, X_m) = C'_1 \lor C'_2 \cdots \lor C'_s$。可以看出任意两个不同的 $C'_i$ 和 $C'_k$均满足 $C'_i \land C'_k = 0$，因此 $C'_i$ 和 $C'_k$ 表示的集合 $Y_i$ 和 $Y_k$ 满足 $Y_i \cap Y_k = \emptyset$。因此，每个 $C'_i$ 表示一个互不相交的集合。

最后，证明每个 $C'_i$ 都可以化简为 $X_j$-局部的集合谓词公式：
根据定义，$C'_i$ 是先前合取项 $C_k$ ($1 \le k < i$) 的否定与 $C_i$ 的合取：
$$C'_i = \bigwedge_{k=1}^{i-1} \neg C_k \land C_i.$$
由于 $C_i$ 可以写成 $(x \in X_j) \land D_i$ 的形式（其中 $D_i$ 是合取项的剩余部分），代入 $C'_i$ 得到：
$$C'_i = \bigwedge_{j=1}^{i-1} \neg C_j \land (x \in X_j) \land D_i = (x \in X_j) \land D'_i.$$
此时，$D'_i$ 可能仍包含与 $X_j$ 相关的原子命题。要消除这些冗余项从而满足定义 \ref{def:local}，一个关键观察是：要使 $C'_i = 1$ 成立，条件 $x \in X_j$ 必须为真。因此，可以将 $C'_i$ 中所有形如 $x \in X_j$ 的项赋值为真，所有形如 $x \notin X_j$ 的项赋值为假，从而得到一个等价公式 $Q_i = (x \in X_j) \land Q'_i$。因为 $Q'_i$ 中不再包含任何与 $X_j$ 相关的原子命题，因此 $Q_i$ 满足 $X_j$-局部的集合谓词公式的定义。证毕。
\end{proof}

为了更直观地理解定理 \ref{theorem:set2}，下面给出三方场景下的3个可构造集合：交集 $Y = X_1 \cap X_2 \cap X_3$、并集 $Y = X_1 \cup X_2 \cup X_3$ 以及一个复合集合公式 $Y = ((X_1 \cap X_2) \cup (X_1 \cap X_3)) \setminus (X_1 \cap X_2 \cap X_3)$，并给出了每个可构造集合对应的 CSPF 表示 $\psi(x, X_1, X_2, X_3)$：

\begin{trivlist}
    \item \textbf{交集.} $\psi(x, X_1, X_2, X_3) = (x \in X_1) \land (x \in X_2) \land (x \in X_3)$。
    在该情况下，$\psi$ 是单个子公式 $Q_1 = \psi$ 的析取，其表示的集合 $Y_1 = Y$。$Q_1$ 相对于 $X_1, X_2, X_3$ 均是局部的，并且 $Y_1$ 本身即为 $Y$ 的一个划分，因此 $\psi$ 满足定义 \ref{def:cspf}。
    \item \textbf{并集.} $\psi(x, X_1, X_2, X_3) = (x \in X_1) \lor ((x \notin X_1) \land (x \in X_2)) \lor ((x \notin X_1) \land (x \notin X_2) \land (x \in X_3))$。
    $\psi$ 是三个子公式 $Q_1, Q_2, Q_3$ 的析取，其中每个 $Q_i = (x \notin X_1) \land \cdots \land (x \notin X_{i-1}) \land (x \in X_i)$ 表示集合 $Y_i = X_i \setminus (X_1 \cup \cdots \cup X_{i-1})$，并且是 $X_i$-局部的集合谓词公式，$\{Y_1, Y_2, Y_3\}$ 是 $Y$ 的一个划分，因此 $\psi$ 满足定义 \ref{def:cspf}。
    \item \textbf{复合集合公式.} 在该情况下，$Y$ 可表示为下面两种不同的 CSPF：
    \begin{itemize}[itemsep=2pt,topsep=0pt,parsep=0pt,leftmargin=10pt]
      \item $\psi(x, X_1, X_2, X_3) = ((x \in X_1) \land (x \in X_2) \land (x \notin X_3)) \lor ((x \in X_1) \land (x \in X_3) \land (x \notin X_2))$。$\psi$ 是两个子公式 $Q_1, Q_2$ 的析取，其中 $Q_1$ 和 $Q_2$ 分别表示集合 $Y_1 = X_1 \cap X_2 \setminus X_3$ 和 $Y_2 = X_1 \cap X_3 \setminus X_2$。$Q_1$ 相对于 $X_1$ 和 $X_2$ 是局部的，而 $Q_2$ 相对于 $X_1$ 和 $X_3$ 是局部的，并且 $\{Y_1, Y_2\}$ 是 $Y$ 的一个划分，因此 $\psi$ 满足定义 \ref{def:cspf}。
      \item $\psi(x, X_1, X_2, X_3) = (x \in X_1) \land [((x \in X_2) \land (x \notin X_3)) \lor ((x \in X_3) \land (x \notin X_2))]$。将 $\psi$ 看作单个子公式 $Q_1 = \psi$ 的析取，其中 $Q_1$ 相对于 $X_1$ 是局部的，因此 $\psi$ 满足定义 \ref{def:cspf}。
      \end{itemize}
\end{trivlist}

第三个例子表明，给定可构造集合 $Y$，其 CSPF 表示通常并不唯一。不同的 CSPF 表示中对应的子公式数量将直接影响后续计算 $Y$ 的 MPSO 协议的计算与通信开销，因此，在实际构造中应尽可能减少子公式数量以提升整体效率。

\section{谓词零分享}~\label{sec:pzs}
\esection{Predicative Zero-Sharing}

本节引入一种新型密码学原语 —— 谓词零分享（Predicative Zero-Sharing）。该原语本质上是一类协议族，其中每个协议都与一个谓词公式相关联，其核心功能是将该公式在参与方输入上的真值“不经意地”编码为参与方之间的一个零分享（当真值结果为真时）或随机分享（当真值结果为假时）。该原语可以看作是多种现有 MPC 协议的统一抽象，并为后续 MPSO 框架的设计提供统一的组合接口。

\subsection{功能定义}\label{def:pzs}

谓词零分享协议允许 $m$ ($m \ge 2$) 个持有私有输入的参与方获得一组在有限域 $\mathbb{F}$ 上的秘密分享：如果与协议相关联的谓词公式 $Q$ 在所有参与方的输入上的取值为真，那么参与方获得 $0$ 的秘密分享；否则，参与方获得一个独立且均匀采样的随机值的秘密分享。该\textbf{概率性}功能 $\FuncPZS^Q$ 的形式化定义如图~\ref{fig:func-pzs} 所示。

\begin{figure}[!hbtp]
\begin{framed}
\begin{minipage}[center]{\textwidth}
\begin{trivlist}
\item \textbf{参数：} $m$ 个参与方 $P_1, \cdots P_m$，输入向量为 $\textbf{x} = (x_1, \cdots, x_m)$；有限域 $\mathbb{F}$；指定谓词公式 $Q$。
\item \textbf{功能：} 收到每个参与方 $P_i$ 的输入 $x_i$后，随机采样分享值 $s_i \gets \mathbb{F}$，且满足：若 $Q(\textbf{x}) = 1$，则 $s_1 + \cdots + s_m = 0$。将分享份额 $s_i$ 发送给 $P_i$。

\subsection{安全性松弛}\label{relaxed-pzs}

谓词零分享的提出源于对许多现有 MPC 协议的高度抽象。鉴于该功能的概率性本质，这些协议必须满足定义~\ref{def:prob-secure} 才能安全地计算谓词零分享。该定义蕴含以下结论：当 $Q(x) = 0$ 时，参与方之间分享的随机秘密值独立于任意 $m-1$ 个参与方的联合视图。在这些协议中，一些协议，例如第三章提出的 mss-ROT，其安全性严格遵循标准定义，实现了标准的谓词零分享功能；然而，我们注意到，更广泛的一类协议，例如 ROT 和等值条件随机数生成（Equality-Conditional Randomness Generation, ECRG）~\cite{Jia0ZG24} 实现的是一种类似的功能，其不同之处在于：若 $Q(x) = 0$，则参与方之间分享的均匀随机秘密值并不独立于任意 $m-1$ 个参与方的联合视图。
下面以 ROT 为例说明 ROT 协议实现了该类松弛版本的谓词零分享（Relaxed Predicative Zero-Sharing）功能（其关联谓词公式为用于测试选择比特是否为 $1$ 的简单谓词：设发送方 $\Sd$ 将其分享份额设置为 $s_1 = -r_0$，其中 $r_0$ 是来自 ROT 的第一条消息；设接收方 $\Rcv$ 将其分享份额设置为 $s_2 = r_e$，即接收到的消息。鉴于 ROT 的功能可以表示为 $-r_0 + r_e = e \cdot (-r_0 + r_1)$，若 $e = 0$，则 $s_1 + s_2 = 0$；否则，$s_1 + s_2 = -r_0 + r_1$，该值是均匀随机分布的，但依赖于发送方 $\Sd$ 视图中 ROT 的输出消息。

由于上述协议安全性的松弛难以基于定义~\ref{def:prob-secure} 精准刻画，下面为谓词零分享引入一种等价的安全性定义，该定义由三个核心要求组成：正确性、隐私性和独立性。以下定理不仅给出了该定义的详细描述，并且严格声明了其与标准安全性定义的等价性。

\begin{theorem}\label{security}
考虑一个概率多项式的 $m$ 元功能 $\Func^f$，其接收各参与方的输入 $\textbf{x} = (x_1, \cdots, x_m)$，并向各参与方输出 $f(\textbf{x})$ 的秘密分享。令 $\Pi$ 为用于计算 $\Func^f$ 的 $m$ 方协议，$s_i$ 和 $s^{\Pi}_i$ 分别用来表示参与方 $P_i$ 在理想世界中从 $\Func^f$ 获得的输出以及在真实世界中实际执行 $\Pi$ 获得的输出（$1 \le i \le m$）。
若协议 $\Pi$ 满足：
\begin{itemize}[itemsep=2pt,topsep=0pt,parsep=0pt,leftmargin=10pt]
    \item \textbf{正确性.} $\Pi$ 的输出构成 $f(\textbf{x})$ 的秘密分享，即：
    $$\{s_1, \cdots, s_m\}_{\textbf{x}} \overset{s}{\approx} \{s^{\Pi}_1, \cdots, s^{\Pi}_m\}_{\textbf{x}}$$
    \item \textbf{隐私性.} 存在一个概率多项式时间的算法 $\mathsf{Sim}$，使得对于任意规模为 $t < m$ 个的参与方子集 $\textbf{P}_{\mathcal{A}} = \{P_{i_1},\cdots,P_{i_t}\}$，满足：
    \begin{gather*}
    \{\mathsf{Sim}(\textbf{P}_{\mathcal{A}},\textbf{x}_{\mathcal{A}},\textbf{s}_{\mathcal{A}})\}_{\textbf{x}} \overset{c}{\approx} \{\mathsf{View}_{\mathcal{A}}^\Pi(\textbf{x})\}_{\textbf{x}}
    \end{gather*}
    \item \textbf{独立性.} 在协议 $\Pi$ 的实际执行过程中，对于任意规模为 $t < m$ 个的参与方子集 $\textbf{P}_{\mathcal{A}} = \{P_{i_1},\cdots,P_{i_t}\}$，$f(\textbf{x})$ 所依赖的随机性独立于敌手的视图 ${\mathsf{View}}_{\mathcal{A}}^\Pi(\textbf{x})$。
\end{itemize}
则存在一个概率多项式时间算法 $\mathsf{Sim}$，使得对于任意 $\textbf{P}_{\mathcal{A}} = \{P_{i_1},\cdots,P_{i_t}\}$，满足：
\begin{gather*}
    \{\mathsf{Sim}(\textbf{P}_{\mathcal{A}},\textbf{x}_{\mathcal{A}},\textbf{s}_{\mathcal{A}}),s_1, \cdots, s_m\}_{\textbf{x}} \overset{c}{\approx} \{\mathsf{View}_{\mathcal{A}}^\Pi(\textbf{x}),s^{\Pi}_1, \cdots, s^{\Pi}_m\}_{\textbf{x}}
\end{gather*}
即模拟器在理想世界中模拟的敌手视图和所有参与方从理想功能 $\Func^f$ 获得的输出的联合分布与敌手在真实世界中的视图和实际执行协议 $\Pi$ 获得的输出的联合分布是计算不可区分的。
\end{theorem}

\begin{proof}
我们通过对敌手 $\mathcal{A}$ 腐化的参与方数量 $t$ 进行归纳来证明该定理。

\begin{trivlist}
\item[$-$] \textbf{基础情况：$\mathbf{t = m-1}$}

假设 $\mathcal{A}$ 腐化了 $t = m-1$ 个参与方。记被腐化参与方的集合为 $\textbf{P}_{\mathcal{A}} = \{P_{i_1}, \cdots, P_{i_{m-1}}\}$，则仅剩一名诚实参与方 $P_h$。根据隐私性要求，存在模拟器 $\mathsf{Sim}$ 满足：
\begin{gather*}
    \{\mathsf{Sim}(\textbf{P}_{\mathcal{A}},\textbf{x}_{\mathcal{A}},\textbf{s}_{\mathcal{A}})\}_{\textbf{x}} \overset{c}{\approx} \{\mathsf{View}_{\mathcal{A}}^\Pi(\textbf{x})\}_{\textbf{x}}
\end{gather*}

令 $\textbf{r}$ 和 $\textbf{r}^\Pi$ 分别表示理想世界和真实世界中 $f(\textbf{x})$ 依赖的随机性。显然，在理想世界中，$\textbf{r}$ 独立于 $\mathsf{Sim}(\textbf{P}_{\mathcal{A}},\textbf{x}_{\mathcal{A}},\textbf{s}_{\mathcal{A}})$。同时，根据独立性要求，真实世界中的 $\textbf{r}^\Pi$ 独立于 $\mathsf{View}_{\mathcal{A}}^\Pi(\textbf{x})$，因此可以得出：
\begin{gather*}
    \{\mathsf{Sim}(\textbf{P}_{\mathcal{A}},\textbf{x}_{\mathcal{A}},\textbf{s}_{\mathcal{A}}),\textbf{r}\}_{\textbf{x}} \overset{c}{\approx} \{\mathsf{View}_{\mathcal{A}}^\Pi(\textbf{x}),\textbf{r}^\Pi\}_{\textbf{x}}
\end{gather*}
由于每个被腐化参与方 $P_i$ 从理想功能获得的输出 $s_{i}$ 和从协议实际执行获得的 $s^\Pi_{i}$均可分别从其在理想世界和真实世界中的视图计算得出（其中 $i \in \{i_1,\cdots,i_{m-1}\}$），因此可将上述不可区分性扩展为：
\begin{gather*}
    \{\mathsf{Sim}(\textbf{P}_{\mathcal{A}},\textbf{x}_{\mathcal{A}},\textbf{s}_{\mathcal{A}}),\textbf{s}_{\mathcal{A}}, \textbf{r}\}_{\textbf{x}} \overset{c}{\approx} \{\mathsf{View}_{\mathcal{A}}^\Pi(\textbf{x}),\textbf{s}^\Pi_{\mathcal{A}}, \textbf{r}^\Pi\}_{\textbf{x}}
\end{gather*}
其中 $\textbf{s}^\Pi_{\mathcal{A}} = (s^\Pi_{i_1}, \cdots, s^\Pi_{i_{m-1}})$。

根据功能定义，诚实参与方 $P_h$ 的输出满足 $s_h = -(\sum_{s_i \in \textbf{s}_{\mathcal{A}}} s_i) + f(\textbf{x})$。由正确性要求可知，$s^\Pi_h = -(\sum_{s^\Pi_i \in \textbf{s}^\Pi_{\mathcal{A}}} s^\Pi_i) + f(\textbf{x})$。将不可区分符号两边的分布分别包含 $s_h$ 和 $s^\Pi_h$：
\begin{gather*}
    \{\mathsf{Sim}(\textbf{P}_{\mathcal{A}},\textbf{x}_{\mathcal{A}},\textbf{s}_{\mathcal{A}}),\textbf{s}_{\mathcal{A}},s_h, \textbf{r}\}_{\textbf{x}} \overset{c}{\approx} \{\mathsf{View}_{\mathcal{A}}^\Pi(\textbf{x}),\textbf{s}^\Pi_{\mathcal{A}},s^\Pi_h, \textbf{r}^\Pi\}_{\textbf{x}}
\end{gather*}
上述不可区分性仍成立，是因为 $s_h$（对应地，$s^\Pi_h$）由 $\textbf{s}_{\mathcal{A}}$（对应地，$\textbf{s}^\Pi_{\mathcal{A}}$）、随机性 $\textbf{r}$（对应地，$\textbf{r}^\Pi$）以及各方输入 $\textbf{x}$ 共同唯一确定。由此可推导出：
\begin{gather*}
    \{\mathsf{Sim}(\textbf{P}_{\mathcal{A}},\textbf{x}_{\mathcal{A}},\textbf{s}_{\mathcal{A}}),\textbf{s}_{\mathcal{A}},s_h\}_{\textbf{x}} \overset{c}{\approx} \{\mathsf{View}_{\mathcal{A}}^\Pi(\textbf{x}),\textbf{s}^\Pi_{\mathcal{A}},s^\Pi_h\}_{\textbf{x}}
\end{gather*}
即当敌手 $\mathcal{A}$ 腐化 $t = m-1$ 个参与方时，协议 $\Pi$ 能够安全地计算 $f$。请注意，此时的独立性要求意味着 $\textbf{r}^\Pi$ 独立于实际执行中任意 $m-1$ 个参与方的联合视图，这将在后续证明中使用。

\item[$-$] \textbf{归纳假设：$\mathbf{t = m-k}$}

假设对于任何腐化 $t = m-k$ 个参与方（$1 \le k < m-1$）的敌手 $\mathcal{A}$，$\Pi$ 均能安全计算 $f$。即存在模拟器 $\mathsf{Sim}$ 满足：
\begin{gather*}
    \{\mathsf{Sim}(\{P_1, \cdots, P_m\} \setminus \textbf{P}_\mathcal{H},\{x_{1},\cdots,x_{m}\} \setminus \textbf{x}_\mathcal{H}, \{s_{1},\cdots,s_{m}\} \setminus \textbf{s}_\mathcal{H}), \{s_{1},\cdots,s_{m}\} \setminus \textbf{s}_\mathcal{H}, \textbf{s}_\mathcal{H}\}_{\textbf{x}} \\
    \overset{c}{\approx} \{\{\mathsf{View}_{1}^\Pi(\textbf{x}),\cdots,\mathsf{View}_{m}^\Pi(\textbf{x})\} \setminus \{\mathsf{View}_{\mathcal{H}}^\Pi(\textbf{x})\}, \{s^\Pi_{1},\cdots,s^\Pi_{m}\} \setminus \textbf{s}^\Pi_{\mathcal{H}}, \textbf{s}^\Pi_{\mathcal{H}}\}_{\textbf{x}}
\end{gather*}
其中 $\textbf{P}_\mathcal{H}$ 是诚实参与方集合，$\mathsf{View}_{\mathcal{H}}^\Pi(\textbf{x})$ 表示 $\textbf{P}_\mathcal{H}$ 的联合视图，而 $\textbf{s}_{\mathcal{H}}$ 和 $\textbf{s}^\Pi_{\mathcal{H}}$ 分别是理想世界和真实世界中的对应输出。

显然，在理想世界中，$\textbf{s}_{\mathcal{H}}$ 独立于联合分布 $\{\mathsf{Sim}(\dots),\{s_{1},\dots,s_{m}\} \setminus \textbf{s}_\mathcal{H}\}$。因此，可以得出结论：在真实世界中，对于任意规模为 $k$ 的参与方子集 $\textbf{P}_\mathcal{H} \subset \{P_1, \cdots, P_m\}$，$\textbf{s}^\Pi_{\mathcal{H}}$ 独立于联合分布 $\{\{\mathsf{View}_{i}^\Pi(\textbf{x})\} \setminus \mathsf{View}_{\mathcal{H}}^\Pi(\textbf{x}),\{s^\Pi_{i}\} \setminus \textbf{s}^\Pi_{\mathcal{H}}\}$。

\item[$-$] \textbf{归纳步骤：$\mathbf{t = m-k-1}$}

我们继续证明敌手 $\mathcal{A}$ 腐化 $t = m-k-1$ 个参与方的情况：

令 $\textbf{P}_{\mathcal{H}'}$ 代表 $\{P_1, \cdots, P_m\}$ 中规模为 $k+1$ 的子集。我们将其分解为 $\textbf{P}_{\mathcal{H}'} = \{\textbf{P}_{\mathcal{H}}, P_h\}$，其中 $\textbf{P}_\mathcal{H}$ 包含恰好 $k$ 个参与方，$P_h$ 为剩余的一个参与方。根据隐私性，我们有：
\begin{equation*}
    \{\mathsf{Sim}(\textbf{P}_{\mathcal{A}},\textbf{x}_{\mathcal{A}},\textbf{s}_{\mathcal{A}}),\textbf{s}_{\mathcal{A}}\}_{\textbf{x}} \overset{c}{\approx} \{\mathsf{View}_{\mathcal{A}}^\Pi(\textbf{x}),\textbf{s}^\Pi_{\mathcal{A}}\}_{\textbf{x}}
\end{equation*}
根据正确性，我们同样有 $\{\textbf{s}_{\mathcal{H}}\}_{\textbf{x}} \overset{c}{\approx} \{\textbf{s}^\Pi_{\mathcal{H}}\}_{\textbf{x}}$。

由归纳假设可知，$\textbf{s}_\mathcal{H}$ 独立于联合分布 $\{\mathsf{View}_{\mathcal{A}}^\Pi(\textbf{x}),\textbf{s}^\Pi_{\mathcal{A}}\}$。同时，$\textbf{s}_{\mathcal{H}}$ 显然独立于理想世界中的联合分布 $\{\mathsf{Sim}(\textbf{P}_{\mathcal{A}},\textbf{x}_{\mathcal{A}},\textbf{s}_{\mathcal{A}}),\textbf{s}_{\mathcal{A}}\}_{\textbf{x}}$。结合上述条件：
\begin{equation*}
    \{\mathsf{Sim}(\textbf{P}_{\mathcal{A}},\textbf{x}_{\mathcal{A}},\textbf{s}_{\mathcal{A}}),\textbf{s}_{\mathcal{A}},\textbf{s}_{\mathcal{H}}\}_{\textbf{x}} \overset{c}{\approx} \{\mathsf{View}_{\mathcal{A}}^\Pi(\textbf{x}),\textbf{s}^\Pi_{\mathcal{A}},\textbf{s}^\Pi_{\mathcal{H}}\}_{\textbf{x}}
\end{equation*}

回顾基础情况中的推导，$\textbf{r}^\Pi$ 独立于实际执行中任意 $m-1$ 个参与方的联合视图，因此 $\textbf{r}^\Pi$ 独立于 $\{\mathsf{View}_{\mathcal{A}}^\Pi(\textbf{x}),\mathsf{View}_{\mathcal{H}}^\Pi(\textbf{x})\}$。由于 $\textbf{s}^\Pi_{\mathcal{A}}$ 和 $\textbf{s}^\Pi_{\mathcal{H}}$ 可分别由 $\mathsf{View}_{\mathcal{A}}^\Pi(\textbf{x})$ 和 $\mathsf{View}_{\mathcal{H}}^\Pi(\textbf{x})$ 确定，故 $\textbf{r}^\Pi$ 独立于 $\{\mathsf{View}_{\mathcal{A}}^\Pi(\textbf{x}),\textbf{s}^\Pi_{\mathcal{A}},\textbf{s}^\Pi_{\mathcal{H}}\}$。此外，理想世界中 $\textbf{r}$ 独立于 $\{\mathsf{Sim}(\textbf{P}_{\mathcal{A}},\textbf{x}_{\mathcal{A}},\textbf{s}_{\mathcal{A}}),\textbf{s}_{\mathcal{A}},\textbf{s}_{\mathcal{H}}\}$，从而可将不可区分性扩展为：
\begin{equation*}
    \{\mathsf{Sim}(\textbf{P}_{\mathcal{A}},\textbf{x}_{\mathcal{A}},\textbf{s}_{\mathcal{A}}),\textbf{s}_{\mathcal{A}},\textbf{s}_{\mathcal{H}}, \textbf{r}\}_{\textbf{x}} \overset{c}{\approx} \{\mathsf{View}_{\mathcal{A}}^\Pi(\textbf{x}),\textbf{s}^\Pi_{\mathcal{A}},\textbf{s}^\Pi_{\mathcal{H}}, \textbf{r}^\Pi\}_{\textbf{x}}
\end{equation*}

根据功能定义，参与方 $P_h$ 的输出满足 $s_{h} = -(\sum_{s_i \in \textbf{s}_{\mathcal{A}}} s_i + \sum_{s_i \in \textbf{s}_{\mathcal{H}}} s_i) + f(\textbf{x})$。
由正确性可知，$s^\Pi_{h} = -(\sum_{s^\Pi_i \in \textbf{s}^\Pi_{\mathcal{A}}} s^\Pi_i + \sum_{s^\Pi_i \in \textbf{s}^\Pi_{\mathcal{H}}} s^\Pi_i) + f(\textbf{x})$。
最后，通过包含 $s_h$ 和 $s^\Pi_h$ 得到：
\begin{equation*}
    \{\mathsf{Sim}(\textbf{P}_{\mathcal{A}},\textbf{x}_{\mathcal{A}},\textbf{s}_{\mathcal{A}}),\textbf{s}_{\mathcal{A}},\textbf{s}_{\mathcal{H}},s_{h},\textbf{r}\}_{\textbf{x}} \overset{c}{\approx} \{\mathsf{View}_{\mathcal{A}}^\Pi(\textbf{x}),\textbf{s}^\Pi_{\mathcal{A}},\textbf{s}^\Pi_{\mathcal{H}},s^\Pi_{h},\textbf{r}^\Pi\}_{\textbf{x}}
\end{equation*}
该不可区分性成立是因为 $s_h$（对应地，$s^\Pi_h$）由 $\textbf{s}_{\mathcal{A}}$、$\textbf{s}_{\mathcal{H}}$（对应地，$\textbf{s}^\Pi_{\mathcal{A}}$、$\textbf{s}^\Pi_{\mathcal{H}}$）、随机性 $\textbf{r}$（对应地，$\textbf{r}^\Pi$）以及输入 $\textbf{x}$ 共同唯一确定。由此导出：
\begin{gather*}
    \{\mathsf{Sim}(\textbf{P}_{\mathcal{A}},\textbf{x}_{\mathcal{A}},\textbf{s}_{\mathcal{A}}),\textbf{s}_{\mathcal{A}},s_h\}_{\textbf{x}} \overset{c}{\approx} \{\mathsf{View}_{\mathcal{A}}^\Pi(\textbf{x}),\textbf{s}^\Pi_{\mathcal{A}},s^\Pi_h\}_{\textbf{x}}
\end{gather*}
即在敌手 $\mathcal{A}$ 腐化 $t = m-k-1$ 个参与方的情况下，$\Pi$ 能够安全地计算 $f$。归纳步骤完成。
\end{trivlist}
\end{proof}

谓词零分享功能 $\FuncPZS^Q$ 是 $\Func^f$ 的一个特例，其中
$$f(\textbf{x}) =
\begin{cases}
  0 & \text{若 } Q(\textbf{x}) = 1 \\
  s & \text{若 } Q(\textbf{x}) = 0
\end{cases}$$
且 $s$ 是一个随机值。可知，$s$ 是 $f$ 所依赖的随机性，将其在协议实际执行中的值记为 $s^\Pi$。在谓词零分享这一特例下，独立性要求具体为：若 $Q(\textbf{x}) = 0$，则在协议 $\Pi$ 的执行过程中，秘密值 $s^{\Pi} = s^{\Pi}_1 + \cdots + s^{\Pi}_m$ 的分布独立于 $\mathsf{View}_{\mathcal{A}}^\Pi(\textbf{x})$。综上，谓词零分享协议的正确性和独立性要求共同保证了：若 $Q(\textbf{x}) = 0$，则各参与方执行协议 $\Pi$ 获得的输出构成的秘密分享中的秘密值 $s^{\Pi}$ 是均匀随机分布的，且独立于任意 $t \le m-1$ 个参与方的联合视图。

\begin{remark}
后文中将使用上述给出的等价的安全性定义 —— 通过分别证明满足正确性、隐私性和独立性，来证明本工作中所有谓词零分享协议的安全性。在该安全性定义下，我们将仅满足正确性和隐私性要求的谓词零分享协议称为\textbf{松弛谓词零分享}，并将与谓词公式 $Q$ 相关联的松弛谓词零分享功能记作 $\FuncrPZS^Q$。
\end{remark}

\subsection{从松弛到标准的转化技术}\label{transform-pzs}

本节给出一种将松弛谓词零分享转化为关联相同谓词公式的满足标准半诚实安全的谓词零分享的高效方法：
假设所有参与方已调用松弛谓词零分享协议 $\ProtorPZS^Q$ 获得了一组秘密分享 $[r] = (r_1, \cdots, r_m)$，其目标是生成一组满足标准谓词零分享安全性定义的秘密分享 $[s] = (s_1, \cdots, s_m)$。为此，参与方只需在离线阶段准备一组随机值的秘密分享 $[b]$（由每个参与方 $P_i$ 采样一个均匀随机的分享份额 $b_i$），并在在线阶段协作执行一次安全乘法计算 $[s] = [r] \cdot [b]$。

\begin{theorem} \label{theorem:bssPMT}
在 $\FuncrPZS^Q$ 和安全乘法的混合模型下，上述协议安全地实现了功能 $\FuncPZS^Q$。
\end{theorem}

\begin{trivlist}
\item \textbf{正确性与独立性。} 设有限域大小 $\lvert \mathbb{F} \rvert \ge 2^\sigma$，由松弛谓词零分享协议 $\ProtorPZS^Q$ 的正确性可知：
\begin{itemize}[itemsep=2pt,topsep=5pt,parsep=0pt,leftmargin=10pt]
    \item 若 $Q(\textbf{x}) = 1$，$r = 0$，则 $s = 0$。
    \item 若 $Q(\textbf{x}) = 0$，$r$ 是均匀随机分布的。用 $E$ 表示事件秘密值 $s$ 是均匀随机且独立于任意 $t \le m-1$ 个参与方的联合视图。用 $E_0$ 和 $E_1$ 分别表示事件 $r = 0$ 和 $r \ne 0$。由于 $b$ 是均匀随机且独立分布的，我们有事件 $E$ 发生的概率为 $Pr[E] = Pr[E \vert E_0] \cdot Pr[E_0] + Pr[E \vert E_1] \cdot Pr[E_1] = 0 \cdot Pr[E_0] + 1 \cdot Pr[E_1] = Pr[E_1] = 1 - Pr[E_0] = 1 - \frac{1}{\lvert \mathbb{F} \rvert} \ge 1- 2^{-\sigma}$。
\end{itemize}
\item \textbf{隐私性。} 该协议的隐私性直接继承自底层原语松弛谓词零分享和安全乘法计算协议的隐私性。具体地，在理想世界中，给定协议输出的前提下，模拟器依次调用松弛谓词零分享与安全乘法计算协议的子模拟器。只要松弛谓词零分享与安全乘法计算协议安全地实现了各自的理想功能，则模拟器在理想世界中模拟的敌手视图（即两个子模拟器在理想世界中模拟的敌手视图的联合分布）与敌手在真实世界中的视图（敌手分别在两个子协议的调用过程中视图的联合分布）是计算不可区分的。
\end{trivlist}

鉴于松弛谓词零分享输出的秘密分享中的均匀随机秘密值依赖于某些 $t \le m-1$ 个参与方的联合视图，在调用谓词零分享后对这些秘密值进行重构时，若这 $t$ 个参与方发生共谋，则可能会泄露信息。该转化技术通过消除这种依赖性来防止此类泄露。这一步骤对于确保我们的 MPSO 框架在抵御任意共谋攻击时的安全性至关重要。该转化技术可以利用 Beaver 三元组 \cite{Beaver-CRYPTO-1991} 对在线阶段进行如下优化：

首先回顾 Beaver 三元组技术。一个 Beaver 三元组由三个秘密分享 $([a], [b], [c])$ 组成，其中 $[a]$ 和 $[b]$ 是随机的秘密分享，且满足 $c = a \cdot b$。通常情况下，Beaver 三元组用于在在线阶段将一次乘法运算规约为两次重构过程；而在此处，由于乘数 $b$ 本身是随机的，Beaver 三元组可用于在在线阶段将一次乘法运算规约为仅一次重构过程。具体而言：
\begin{gather*}
s = r \cdot b = (r+a-a) \cdot b = (r+a) \cdot b - a \cdot b
\end{gather*}
因此我们可以计算：
\begin{gather*}
[s] = (r+a) \cdot [b] - [a \cdot b] = (r+a) \cdot [b] - [c]
\end{gather*}
上述等式表明，一旦 $u = r + a$ 公开，我们就可以在本地计算 $[s]$。因此，生成 $[s]$ 的任务便简化为重构 $[u] = [r] + [a]$。令每个参与方 $P_i$ 在本地计算其分享份额 $u_i = r_i + a_i$ 并将 $u_i$ 发送给 Leader 节点 $P_1$，随后 $P_1$ 计算 $u = u_1 + \cdots + u_m$ 并将其向所有参与方公开。由此可见，该转化技术仅消耗一个在离线阶段生成的 Beaver 三元组；在在线阶段，Leader 节点的通信开销为 $2 (m-1) \log_2\lvert \mathbb{F} \rvert$，每个 Client 节点的通信开销为 $2 \log_2\lvert \mathbb{F} \rvert$。

上述优化后的转化技术采用星型通信拓扑，这使其能够集成到后续将介绍的 MPSO 协议中而不改变其原有拓扑结构 —— 从而在保证其标准半诚实安全性的同时，实现优越的复杂度性能（参见第~\ref{sec:mpsi} 节和第~\ref{sec:mpsu} 节）。

\subsection{从简单到复合的组合技术}\label{compound-pzs}

根据所关联的谓词公式 $Q$ 的类型，可将谓词零分享协议分为两类：若 $Q$ 是一个简单谓词，则称之为简单谓词零分享（Simple Predicative Zero-Sharing）；若 $Q$ 是一个复合谓词，即 $Q$ 由 $q>1$ 个文字（原子命题或其否定）和逻辑联结词 $\land$ 与 $\lor$ 构成，其中每个文字 $Q_i$ 是一个简单谓词或其否定 ($1 \le i \le q$)，则称对应的谓词零分享为复合谓词零分享（Compound Predicative Zero-Sharing）。本节将介绍将简单谓词零分享协议组合成复合谓词零分享协议的高效方法 —— 对于任何复合谓词 $Q$，只要为其中每个文字 $Q_i$ 构造对应的松弛版本的简单谓词零分享协议，就可以构造与 $Q$ 相关联的满足标准半诚实安全的复合谓词零分享协议。

总的来说，构造与 $Q$ 相关联的的复合谓词零分享协议可分为三个阶段：首先，参与方为每个文字 $Q_i$ 执行对应的松弛简单谓词零分享协议。对于仅涉及参与方子集的文字，未参与的参与方将其缺失的分享份额设置为 $0$；其次，参与方参照由所有文字通过逻辑与 $\mathsf{AND}$、逻辑或 $\mathsf{OR}$ 操作符组合成公式 $Q$ 的计算过程，逐步对持有的秘密分享进行协同处理，将其组合成一个满足与 $Q$ 相关联的松弛版本的复合谓词零分享定义的输出秘密分享。其中，在每一步结束时，参与方都会获得一个与当前计算的中间公式相对应的秘密分享；最后，参与方将松弛复合谓词零分享转化为足标准半诚实安全的复合谓词零分享。完整的构造过程详见图~\ref{fig:proto-cpzs}。

\item \textbf{模拟公式计算阶段.} 若 $q>1$，参与方按照操作符的优先级，逐步模拟 $Q$ 的计算。在其中的每一步中，参与方模拟两个谓词 $Q'_i$ 和 $Q'_j$ 通过逻辑操作符连接成一个谓词公式 $Q'$ 的计算 —— 参与方已经从前一步获得了与 $Q'_i$ 和 $Q'_j$ 对应的秘密分享，目标是生成一组满足与 $Q'$ 相关联的松弛谓词零分享输出的秘密分享。具体的操作取决于所计算的操作符类型：

\end{itemize}

\end{theorem}

\begin{trivlist}
\item \textbf{正确性与独立性。} 在模拟公式计算阶段的每一步中：
\begin{itemize}[itemsep=2pt,topsep=5pt,parsep=0pt,leftmargin=10pt]
    \item 若 $Q'(\textbf{x}) = Q'_i(\textbf{x}) \land Q'_j(\textbf{x})$，参与方计算 $[r_i + r_j] = [r_i] + [r_j]$。若 $Q'(\textbf{x}) = 1$，即 $Q'_i(\textbf{x}) = 1$ 且 $Q'_j(\textbf{x}) = 1$，根据 $\FuncrPZS^{Q'_i}$ 和 $\FuncrPZS^{Q'_j}$ 的功能可知 $r_i = 0$ 且 $r_j = 0$，因此 $r_i + r_j = 0$；否则，$Q'_i(\textbf{x}) = 0$ 或 $Q'_j(\textbf{x}) = 0$，根据 $\FuncrPZS^{Q'_i}$ 和 $\FuncrPZS^{Q'_j}$ 的功能 $r_i$ 和 $r_j$ 中至少有一个是随机值，故 $r_i + r_j$ 也是随机值。
    \item 若 $Q'(\textbf{x}) = Q'_i(\textbf{x}) \lor Q'_j(\textbf{x})$，参与方计算 $[r_i \cdot r_j] = [r_i] \cdot [r_j]$。若 $Q'(\textbf{x}) = 1$，即 $Q'_i(\textbf{x}) = 1$ 或 $Q'_j(\textbf{x}) = 1$，根据 $\FuncrPZS^{Q'_i}$ 和 $\FuncrPZS^{Q'_j}$ 的功能 $r_i = 0$ 或 $r_j = 0$，因此 $r_i \cdot r_j = 0$；否则，$Q'_i(\textbf{x}) = 0$ 且 $Q'_j(\textbf{x}) = 0$，则 $r_i$ 和 $r_j$ 均为随机值。用 $E^{i,j}$ 表示事件 $r_i \cdot r_j$ 是随机值。用 $E_0^{i}$ 表示事件 $r_i = 0$，$E_1^{i}$ 表示事件 $r_i \ne 0$。我们有事件 $E^{i,j}$ 发生的概率为 $Pr[E^{i,j}] = Pr[E^{i,j} \vert E_0^{i}] \cdot Pr[E_0^{i}] + Pr[E \vert E_1^{i}] \cdot Pr[E_1^{i}] = 0 \cdot Pr[E_0^{i}] + 1 \cdot Pr[E_1^{i}] = Pr[E_1^{i}] = 1- Pr[E_0^{i}]$。为了将正确性误差限制在 $2^{-\sigma}$ 以内，要求任何 $E_0^{i}$ 发生的概率是可忽略的。通过联合界（Union Bound），$Pr[\bigvee_i E_0^{i}] \le \sum_{i} Pr[E_0^{i}] = \frac{\lvert \mathsf{OR} \rvert}{\lvert \mathbb{F} \rvert}$。因此，需设置有限域大小 $\lvert \mathbb{F} \rvert \ge \lvert \mathsf{OR} \rvert \cdot 2^\sigma$，其中 $\lvert \mathsf{OR} \rvert$ 是 $Q$ 中 $\mathsf{OR}$ 操作符的数量。
\end{itemize}
上面模拟公式计算阶段中每一步模拟 $\mathsf{AND}$ 和 $\mathsf{OR}$ 操作符计算的正确性，保证了该阶段实现与 $Q$ 相关联的松弛谓词零分享协议的正确性。根据第~\ref{transform-pzs} 节中的正确性和独立性分析，最终协议满足与 $Q$ 相关联的标准谓词零分享的正确性和独立性要求。
\item \textbf{隐私性。} 谓词零分享的隐私性易于验证：由于所有交互均发生在对构建模块（即所有松弛简单谓词零分享协议、安全乘法计算及转化技术）的调用内部，因此给定理想功能的输出，模拟器只需以反向链式的方式调用这些构建模块的子模拟器。最终，只要所有松弛简单谓词零分享协议、安全乘法计算和转化技术的隐私性成立，那么敌手的视图在理想世界和真实世界中就是不可区分的。
\end{trivlist}

\section{成员零分享（Membership Zero-Sharing）}

谓词零分享刻画了一类 MPC 协议的统一抽象。只有指定相关联的谓词公式，谓词零分享才可被实例化为具体协议。为了在 MPSO 语境下实例化谓词零分享，本节引入了一类更具体的 MPC 协议 —— 成员零分享（Membership Zero-Sharing），作为谓词零分享的一个子集，每个成员零分享协议都与一个集合谓词公式相关联，并构成后续 MPSO 框架的技术核心。

本节的目标是为任意一阶集合谓词公式构造完整的成员零分享协议。从宏观来看，我们的构造遵循图~\ref{fig:proto-cpzs} 中给出的构建谓词零分享的技术路线。要构造具体协议，我们还需要实例化其中的松弛谓词零分享组件 —— 更具体地，在本章集合谓词公式的语境下，松弛成员零分享。鉴于任何集合谓词公式仅由两类文字组成 —— 集合成员谓词 $x \in Y$ 及其否定 $x \notin Y$，因此问题可归约为在两方场景下分别构造与这两个简单谓词相关联的松弛成员零分享协议。

\subsection{功能定义}\label{compound-mzs}

成员零分享协议允许 $m$ ($m \ge 2$) 个参与方参与，其中一个参与方（记为 $P_\mathsf{pivot}$）持有一个元素 $x$ 作为输入，而其他每个参与方 $P_j$ ($j \in \{1,\cdots,m\} \setminus \{\mathsf{pivot}\}$) 持有一个集合 $X_j$ 作为输入。如果关联的集合谓词公式 $Q(x,X_1,\cdots,X_{\mathsf{pivot}-1},X_{\mathsf{pivot}+1},\cdots, X_m) = 1$，参与方将获得 $0$ 的秘密分享；否则，他们将获得一个随机值的秘密分享。

图~\ref{fig:func-bmzs} 定义了成员零分享的批量版本，其中 $P_\mathsf{pivot}$ 持有一个向量 $\textbf{x} = (x_1, \cdots, x_n)$，而每个 $P_j$ 持有 $n$ 个集合序列作为输入。参与方获得 $n$ 组秘密分享，其中第 $i$ 组秘密分享表示对第 $i$ 个输入计算相同公式 $Q$ 得到的真值。

% 特别地，若 $Q$ 是 $m-1$ 个集合成员谓词的合取（即 $\bigwedge_{j \in \{1,\cdots,m\} \setminus \{\mathsf{pivot}\}} x \in X_j$），我们将其称为批量纯成员零分享（Batch Pure Membership Zero-Sharing）（适配于第~\ref{sec:mpsi} 节中的 MPSI 及其变体）；若 $Q$ 是 $m-1$ 个集合非成员谓词的合取（即 $\bigwedge_{j \in \{1,\cdots,m\} \setminus \{\mathsf{pivot}\}} x \notin X_j$），我们将其称为批量纯非成员零分享（Batch Pure Non-Membership Zero-Sharing）（适配于第~\ref{sec:mpsu} 节中的 MPSU 及其变体）。这两个功能的正式定义（及其构造）分别在附录~\ref{bpMZS} 和~\ref{bpNMZS} 中给出。我们还引入了纯成员零分享的一种变体，称为带有效载荷的纯成员零分享（Pure Membership Zero-Sharing with Payloads），其中 $P_\mathsf{pivot}$ 持有一个元素 $x$，而其他参与方各持有一个元素集合和一组关联的有效载荷。该功能专为附录~\ref{appdix:mpsi-card-sum} 中的 MPSI-card-sum 设计，其正式定义和构造见附录~\ref{bpMZSpayloads}。

\subsection{针对集合成员谓词的松弛成员零分享}\label{zs-PMT}

针对集合成员谓词 $x \in Y$ 的一类松弛成员零分享可以定义为如下两方功能：包含两个参与方，即持有集合 $Y$ 的发送方 $\Sd$ 和持有元素 $x$ 的接收方 $\Rcv$。该功能采样 $s,r \gets \mathbb{F}$，若 $x \in Y$，则设 $u = -r$；否则 $u = s - r$。同时，它生成一个包含关于 $s$ 的部分信息的中间消息 $\mathsf{leak}$。最后，该功能向 $\Sd$ 输出 $r, \mathsf{leak}$，向 $\Rcv$ 输出 $u$。其中的 $\mathsf{leak}$ 允许在 $x \notin Y$ 时向 $\Sd$ 泄露关于秘密值 $s$ 的部分信息，从而体现了松弛谓词零分享中的安全性松弛。

从 $\Rcv$ 的视角看，若 $x \in Y$，则 $u = -r$；否则由于 $s$ 是由该功能均匀采样的，且 $\Rcv$ 未获得关于 $s$ 的额外信息，故 $u = s - r$ 是随机的。因此，$u$ 可以看作是一个“可编程”随机函数 $f$ 在 $x$ 处的取值，其中 $f$ 在集合 $Y$ 的元素上的取值均被编程为相同的均匀随机值 $-r$，而其他位置的取值为随机值。为了高效实例化该功能，令 $f$ 为一个可编程 PRF（OPPRF）。向 $\Sd$ 泄露的 $\mathsf{leak}$ 即为 PRF 密钥，而 $\Rcv$ 通过与 $\Sd$ 调用 OPPRF 来不经意地计算 $u = f(\mathsf{leak}, x)$。具体构造如下：$\Sd$ 采样一个均匀随机值 $r$，并将 $Y$ 设置为关键字集合，将 $n$ 个重复的值 $-r$ 设置为对应的值集合。随后 $\Sd$ 和 $\Rcv$ 调用 OPPRF，其中 $\Rcv$ 输入 $x$ 并获得 $u$。最后，$\Sd$ 和 $\Rcv$ 分别输出 $r$ 和 $u$。根据 OPPRF 的功能，若 $x \in Y$，则 $u = -r$；否则 $u$ 是伪随机的。向 $\Sd$ 输出的 $\mathsf{leak}$ 即为来自 OPPRF 的 PRF 密钥。该协议可以利用 batch OPPRF 自然地扩展到批量版本。

\subsection{针对集合非成员谓词的松弛成员零分享}\label{zs-PNMT}

针对集合非成员谓词 $x \notin Y$ 的一类松弛成员零分享协议可以定义为如下两方功能：发送方 $\Sd$ 输入集合 $Y$，接收方 $\Rcv$ 输入元素 $x$。该功能采样 $s,r \gets \mathbb{F}$，若 $x \notin Y$，则设 $u = -r$；否则 $u = s - r$。它同样生成一个包含关于 $s$ 的部分信息的中间消息 $\mathsf{leak}$。最后，该功能向 $\Sd$ 输出 $r, \mathsf{leak}$，向 $\Rcv$ 输出 $u$。

该功能在直觉上与秘密分享隐私成员测试（ssPMT）高度相似： —— 两者在 $x \notin Y$ 时均产生 0 的秘密分享。核心区别在于，本协议输出的是有限域 $\mathbb{F}$ 上的零分享，其中输出 $0$ 的秘密分享的对立事件是输出 $\mathbb{F}$ 中一个随机值的秘密分享；而 ssPMT 输出的是 $\mathbb{F}_2$ 上的比特秘密分享，其中输出 $0$ 的秘密分享的对立事件是输出 $1$ 的秘密分享。鉴于第三章中给出了高效的批量秘密分享隐私成员测试（batch ssPMT）构造，我们的目标是高效地将比特秘密分享转化为零分享（批量版本首先由参与方调用 batch ssPMT，随后执行 $n$ 次转化）。回顾第 \ref{def:pzs} 节中，ROT 被视为一种与谓词 $e = 0$ 相关联的松弛简单谓词零分享。ROT 的一种变体涉及由 $\Sd$ 和 $\Rcv$ 分别持有的两个选择比特 $e_0, e_1$~\cite{LG-ASIACRYPT-2023,Jia0ZG24,DongCZB24}，它是一种关联谓词为 $e_0 \oplus e_1 = 0$ 的松弛简单谓词零分享。这种“双选择比特”的 ROT 实际上可以看作是从比特秘密分享到零分享的一种转化：执行协议后，$\Sd$ 获得 $r_0, r_1 \in \mathbb{F}$，而 $\Rcv$ 获得 $r_{e_0 \oplus e_1} \in \mathbb{F}$\footnote{这种双选择比特 ROT 与标准的 2 选 1 ROT 等价，其中 $e_0$ 由 $\Sd$ 采样，用于指示是否交换 $r_0$ 和 $r_1$ 的顺序，如图~\ref{fig:proto-cmzs} 所示。}。令 $\Sd$ 设置 $r = -r_0$，$\Rcv$ 设置 $u = r_{e_0 \oplus e_1}$，则若 $e_0 \oplus e_1 = 0$，有 $r + u = 0$；否则 $r + u = r_1 - r_0 = s$ 是随机的。向 $\Sd$ 泄露的 $s$ 即为 $r_1$（因为 $\Sd$ 获知了 $r_0, r_1$，故可计算 $s$）。

利用上述针对两方松弛成员零分享协议的实例化，并遵循图~\ref{fig:route} 中的技术路线，我们在图~\ref{fig:proto-cmzs} 中给出了针对任意集合谓词公式 $Q$ 的完整批量成员零分享协议。

\item \textbf{参数：} $m$ 个参与方 $P_1, \cdots P_m$，其中 $P_\mathsf{pivot}$ 持有 $n$ 个元素而非 $n$ 个集合。集合谓词公式 $Q$ 由 $q \ge 1$ 个文字 $Q_1,\cdots,Q_q$ 组成，每个 $Q_i$ ($1 \le i \le q$) 的形式为 $x \in X_j$ 或 $x \notin X_j$ ($j \ne \mathsf{pivot}$)。$n$ 个 Beaver 三元组 $([\textbf{a}], [\textbf{b}], [\textbf{c}])$。批量大小 $n$。域 $\mathbb{F}$。

        \item $x \notin X_j$：$P_\mathsf{pivot}$ 和 $P_j$ 调用 $\FuncbssPMT$，在第 $k$ 个实例 ($1 \le k \le n$) 中，$P_j$ 输入 $X_{j,k}$ 并接收 $e_{i,k}^0$，$P_\mathsf{pivot}$ 输入 $x_k$ 并接收 $e_{i,k}^1$。然后他们调用 $n$ 个 ROT 实例，在第 $k$ 个实例中，$P_j$ 作为 $\Sd$ 接收 $r_{i,k}^0,r_{i,k}^1$，$P_\mathsf{pivot}$ 作为 $\Rcv$ 输入 $e_{i,k}^1$ 并接收 $r_{i,k}^{e_{i,k}^1}$。$P_\mathsf{pivot}$ 设置其份额 $\textbf{r}_{i,\mathsf{pivot}} = (r_{i,1}^{e_{i,1}^1},\cdots,r_{i,n}^{e_{i,n}^1})$。$P_j$ 设置其份额 $\textbf{r}_{i,j} = (-r_{i,1}^{e_{i,1}^0}, \cdots, -r_{i,n}^{e_{i,n}^0})$。对于其余每个 $P_{d}$，设置其份额 $\textbf{r}_{i,d} = \textbf{0}$。

\begin{theorem}\label{theorem:bmzs}
在 $(\FuncbOPPRF, \FuncbssPMT, \FuncROT)$-混合模型下，协议 $\ProtobMZS^Q$ 在任意半诚实敌手腐化不超过 $t < m$ 个参与方的情况下，安全地实现了 $\FuncbMZS^Q$。
\end{theorem}

\begin{trivlist}
\item \textbf{正确性与独立性。} 成员零分享的正确性和独立性继承自谓词零分享，仅需针对批量场景调整正确性参数：$\lvert \mathbb{F} \rvert \ge \lvert \mathsf{OR} \rvert \cdot n \cdot 2^\sigma$，其中 $\lvert \mathsf{OR} \rvert$ 是 $Q$ 中 $\mathsf{OR}$ 操作符的数量。

\item \textbf{隐私性。} 成员零分享的隐私性易于验证：所有交互均发生在两个松弛批量成员零分享协议的调用内部，这些协议可进一步分解为三个基础模块—— batch OPPRF、batch ssPMT 和 ROT。因此，给定理想功能的输出，模拟器只需以反向推导的方式调用这些基础模块的子模拟器。只要 batch OPPRF、 batch ssPMT 和 ROT 协议是安全的，敌手的视图在理想世界和真实世界中是不可区分的，从而满足隐私性定义。
\end{trivlist}

\section{实现通用功能及其扩展的 MPSO 框架}
\esection{MPSO Framework with Generic MPSO and Extended Functionalities}

\subsection{技术路线概述}

本章提出的 MPSO 框架可分为两个阶段：第一阶段基于任何可构造集合 $Y$ 的 CSPF 表示 $\psi(x, X_1, \cdots, X_m)$，目标是各方获得与 $Y$ 的一个划分相对应的秘密分享。回顾 $\psi = Q_1 \lor \cdots \lor Q_s$，对于每个子公式 $Q_i$（$1 \le i \le s$），
设 $X_{i_1},\cdots,X_{i_q}$（$1 \le q \le m$）为 $Q_i$ 中所有原子命题涉及的集合，并用 $X_j$ ($j \in \{{i_1},\cdots,{i_q}\}$) 表示 $Q_i$ 相对于其满足局部性的集合。即：$$Q_i(x,X_{i_1},\cdots,X_{i_q}) = (x \in X_j) \land Q'_i(x,X_{i_1},\cdots,X_{j-1},X_{j+1},\cdots,X_{i_q})$$ 其中 $Q'_i$ 是 $Q_i$ 的 $X_j$-局部剩余公式。设 $Y_i$ 为由 $Q_i$ 表示的集合，则 $Q'_i$ 本质上是针对 $X_j$ 中元素关于 $Y_i$ 的成员测试集合谓词公式。我们先给出第一阶段的初步构造：对于每个 $Q_i$，$P_{i_1},\cdots,P_{i_q}$ 调用 $n$ 个与 $Q'_i$ 相关联的成员零分享实例。在每个实例中，$P_j$ 作为 $P_{\mathsf{pivot}}$ 输入 $X_j$ 中的一个元素。对于每个 $x \in X_j$，如果 $Q'_i = 1$，参与方收到 0 的秘密分享，否则收到随机值的秘密分享。$P_j$ 将 $x$ 加到其对应的分享份额上，使得对于每个 $x \in X_j$，如果 $Q_i = 1$（即 $Q'_i = 1$），各方收到 $x$ 的秘密分享，否则还是收到随机值的秘密分享。

在上述初步构造中，针对 $X_j$ 的成员测试需要在大小为 $n$ 的相同输入集合上，重复执行 $n$ 次与 $Q'_i$ 相关联的成员零分享。因此，每个实例的均摊开销相对于 $n$ 的复杂度是 $O(n)$。为了实现 $O(1)$ 的均摊开销，利用哈希分桶（Hashing-to-bins）技术来优化该过程，具体而言：令 $P_j$ 通过布谷鸟哈希预处理 $X_j$，其他参与方通过简单哈希预处理各自的集合。该预处理过程使得 $P_j$ 的每个元素 $x \in X_j$ 仅需与其他参与方拥有的具有相同索引的桶进行比较，同时保持成员测试的正确性。因此，在每个成员零分享实例中，当 $P_j$ 作为 $P_{\mathsf{pivot}}$ 输入其布谷鸟哈希桶的单个元素时，其他参与方只需输入具有相同索引的简单哈希桶中所有元素组成的集合，该集合是输入集合的子集而非整个集合。在 $n$ 次成员零分享调用中，每个输入集合的参与方输入到 $n$ 个成员零分享实例中的集合大小总和等于其简单哈希表的大小，相对于 $n$ 的复杂度是 $O(n)$，因此每个实例的摊销开销被降到 $O(1)$。优化后的第一阶段具体构造如下。

对于每个 $Q_i$，$P_j$ 使用哈希函数 $h_1, h_2, h_3$ 通过布谷鸟哈希将元素分配到 $B = O(n)$ 个桶中，使得每个桶 $\mathcal{C}_j^b$ ($1 \le b \le B$) 最多包含一个元素。同时，每个 $P_{j'}$ ($j' \in \{{i_1},\cdots,{i_q}\}\setminus \{j\}$) 将其每个元素 $y \in X_{j'}$ 分配到桶 $\mathcal{T}_{j'}^{h_1(y)}, \mathcal{T}_{j'}^{h_2(y)}, \mathcal{T}_{j'}^{h_3(y)}$ 中。如果 $P_j$ 将元素 $x \in X_j$ 映射到 $\mathcal{C}_j^b$ 中，则 $b \in \{h_1(x),h_2(x),h_3(x)\}$。如果 $P_{j'}$ 也持有 $x$，则 $x$ 必定也被映射到 $\mathcal{T}_{j'}^b$。这使得除了 $X_j$ 以外的其他参与方能够将其输入集合相对于 $X_j$ 在布谷鸟哈希桶里的排列对齐，从而保证对于 $\mathcal{C}_j^b$ 中的每个 $x$，$x \in X_j'$ 当且仅当 $x$ 在 $\mathcal{T}_{j'}^b$ 中。由此可推导出：$$Q'_i(x,X_{i_1},\cdots,X_{j-1},X_{j+1},\cdots,X_{i_q}) = Q'_i(x,\mathcal{T}_{i_1}^b,\cdots,\mathcal{T}_{j-1}^b,\mathcal{T}_{j+1}^b,\cdots,\mathcal{T}_{i_q}^b).$$ 根据上述关系，让 $P_{i_1},\cdots,P_{i_q}$ 调用与 $Q'_i$ 相关联的批量成员零分享，其中 $P_j$ 作为 $P_{\mathsf{pivot}}$ 输入 $\mathcal{C}_j^1, \cdots, \mathcal{C}_j^B$，每个 $P_{j'}$ 输入 $\mathcal{T}_{j'}^1, \cdots, \mathcal{T}_{j'}^B$。协议结束后，他们收到 $B$ 组秘密分享，使得如果每个桶 $C_j^b$ 中的元素 $x$ 满足 $Q_i(x,X_{i_1},\cdots,X_{i_q}) = 1$（即 $x \in Y_i$），参与方收到 0 的秘密分享，否则收到随机值的秘密分享。最后，$P_j$ 将 $x$ 拼接上全零字符串（用于区分元素与随机值），然后将该值加到自己的第 $b$ 个分享份额上，从而满足：如果 $x \in Y_i$，参与方持有 $x$ 的秘密分享。

鉴于 $\{Y_1, \cdots, Y_s\}$ 构成 $Y$ 的一个划分，如果参与方对所有 $Q_1, \cdots, Q_s$ 执行上述过程，他们将持有 $Y$ 中所有元素的秘密分享（每个元素的秘密分享出现一次，其中混杂着不在 $Y$ 中的元素及重复元素对应的随机秘密分享），这些秘密分享按 $Y_1, \cdots, Y_s$ 的主序排列。在每个 $Y_i$ 内部，对应 $Y_i$ 中元素的秘密分享按 $P_j$ 的布谷鸟哈希位置的次序排列，该顺序取决于整个集合 $X_j$。如果参与方执行上述过程但不执行最后 $P_j$ 将元素加入分享的步骤，各方将在该元素对应的位置持有 0 的秘密分享。是否执行最后的追加元素步骤由 MPSO 框架的目标功能决定，该框架可实现的功能可分为三类：

\noindent\textbf{MPSO.} 为了实现该功能，参与方必须向 $P_1$ 重构 $Y$ 中的所有元素，因此他们必须执行所有的追加元素步骤来对元素进行秘密分享。然而，直接重构秘密分享会导致两类信息泄露：1) 重构出的元素的主序揭示了每个元素所属的子集 $Y_i$。2) 重构出的元素的次序会泄露 $X_j$ 的信息。因此，所有参与方在重构阶段前需调用多方秘密分享洗牌协议，以打乱所有秘密分享的顺序并重新分享所有秘密。在重构阶段后，$P_1$ 识别出所有重构秘密中拼接有全零字符串的值，截取出其中的元素值并输出。

\noindent\textbf{MPSO-card.} 为了实现该功能，参与方必须在不泄露实际元素的情况下重构秘密以获取基数。为此，参与方跳过所有的追加元素步骤，使得对于 $Y$ 中的每个元素，参与方持有 0 的秘密分享；而对于不在 $Y$ 中的元素或重复元素，参与方持有随机秘密分享。如上所述，这些秘密分享也按照相同的顺序排列，因此直接重构会导致与实现 MPSO 构造中相同的信息泄露。所以，参与方同样需要在重构阶段前调用多方秘密分享洗牌协议。随后，他们向 $P_1$ 重构秘密，然后由 $P_1$ 统计所有重构秘密中 0 的数量作为 $Y$ 的基数并输出。

\noindent\textbf{Circuit-MPSO.} 实现 Circuit-MPSO 功能有两种方法：
\begin{itemize}[itemsep=2pt,topsep=5pt,parsep=0pt,leftmargin=10pt]
  \item \textbf{方法 1：} 参与方跳过所有的追加元素步骤。他们将所有秘密分享连同其对应位置的布谷鸟哈希桶中的元素按顺序输入到一个通用 MPC 协议中。该通用 MPC 协议实现如下电路：用于从所有秘密中识别出 0，将所有等于 0 的秘密对应位置的元素组成集合 $Y$，最后计算 $Y$ 上的任意函数。
  \item \textbf{方法 2：} 参与方执行所有的追加元素步骤。他们将秘密分享输入到一个通用 MPC 协议中。该通用 MPC 协议实现如下电路：首先通过是否拼接有全零字符串区分元素与随机值，然后截取出所有的元素值组成集合 $Y$，最后计算 $Y$ 上的任意函数。
\end{itemize}

\subsection{框架构造及安全性证明}

令 $C_{s,B,l}^1$ 和 $C_{N,l'}^2$ 为两个电路：
\begin{itemize}[itemsep=2pt,topsep=5pt,parsep=0pt,leftmargin=10pt]
\item $C_{s,B,l}^1$ 具有 $sB(m\log_2\lvert \mathbb{F} \rvert+ l)$ 条输入线，分为 $s$ 个部分，每部分有 $B(m\log_2\lvert \mathbb{F} \rvert + l)$ 条输入线，其中每 $B$ 个。在第 $i$ 个部分 ($1 \le i \le s$) 中，第 $k$ 组 的 $B$ 个在 $\mathbb{F}$ 上的输入与参与方 $P_k$ ($1 \le k \le m$) 相关联，将该组中的第 $b$ 个输入 ($1 \le b \le B$) 记为 $u_{i,k,b} \in \mathbb{F}$；最后 $B$ 个长度为 $l$ 的输入与特定参与方 $P_j$ ($1 \le j \le m$) 相关联，记其中的第 $b$ 个输入 ($1 \le b \le B$) 为 $z_{i,b} \in \{0,1\}^l$。该电路首先实现下面功能：如果 $u_{i,1,b} + \cdots + u_{i,m,b} = 0$，则产生比特 $w_{i,b} = 1$，否则为 0（针对 $1 \le i \le s, 1 \le b \le B$）。然后，该电路计算并输出 $f(Z)$，其中 $Z = \{z_{i,b} \vert w_{i,b} = 1\}_{1 \le i \le s, 1 \le b \le B}$，$f$ 是要在可构造集合 $Y$ 上计算的函数。
\item $C_{N,l'}^2$ 具有 $m$ 组，每组 $N$ 个在 $\mathbb{F}$ 上的输入。第 $k$ 组与 $P_k$ ($1 \le k \le m$) 相关联，其中第 $i$ 个输入记为 $z_{k,i}$ ($1 \le i \le N$)。电路计算并输出 $f(Z)$，其中 $Z = \{z_i \vert z_{1,i} + \cdots + z_{m,i} = z_i \Vert 0^{l'}\}_{1 \le i \le N}$，$f$ 是要在 $Y$ 上计算的函数。
\end{itemize}

\begin{theorem}\label{theorem:mpso}
在 $(\FuncbMZS^Q, \FuncMS)$-混合模型下，图~\ref{fig:proto-MPSO} 中的 MPSO、MPSO-card 和 Circuit-MPSO 协议在抵御腐化 $t < m$ 个参与方的半诚实敌手时是安全的。
\end{theorem}

\begin{trivlist}
\item \textbf{正确性.} 协议的正确性源于定理~\ref{theorem:set2} 及定义~\ref{def:cspf} 中 CSPF 的性质，以及批量成员零分享的正确性。为确保批量成员零分享的正确性，有限域大小需满足 $\lvert \mathbb{F} \rvert \ge \lvert \mathsf{OR} \rvert \cdot B \cdot 2^\sigma$，其中 $\lvert \mathsf{OR} \rvert$ 是所有子公式中 $\mathsf{OR}$ 操作的总数。

设 $Y_i$ 为 $Q_i$ 表示的集合。在 MPSO 和 Circuit-MPSO 协议（方法 2）中，对于每个 $Q_i$，参与方持有 $\lvert Y_i \rvert$ 个 $Y_i$ 元素的秘密分享和 $B-\lvert Y_i \rvert$ 个随机值的秘密分享。由于 $\{Y_1, \cdots, Y_s\}$ 是 $Y$ 的一个划分，各方总计持有 $\lvert Y \rvert$ 个 $Y$ 元素的秘密分享和 $sB-\lvert Y \rvert$ 个随机值的秘密分享。$P_1$ 或电路通过检查末尾 $l'$ 位是否为全零来识别元素。若随机值与 $0^{l'}$ 碰撞，则产生假阳性。总错误概率上限为 $sB \cdot 2^{-l'}$，为使其可忽略，设置 $l' \ge \sigma + \log s + \log B$。在 MPSO-card 和 Circuit-MPSO（方法 1）中，各方持有 $\lvert Y \rvert$ 个 0 的秘密分享。为将假阳性概率限制在 $2^{-\sigma}$ 内，设置 $\lvert \mathbb{F} \rvert \ge sB \cdot 2^\sigma$。

\item \textbf{安全性.} 与之前对谓词零分享的隐私性证明类似，除最后重构阶段外的所有交互均在对构建模块（批量成员零分享和多方秘密分享洗牌协议）的调用内部完成，因此给定输出 $Y$，模拟器只需以反向链式的方式调用构建模块的子模拟器。模拟的核心难点在于当 $P_1$ 被腐化时如何模拟重构消息。模拟器从理想功能获得 $Y$ 后，将 $Y$ 中元素编码并生成 $\lvert Y \rvert$ 个秘密分享，随后采样 $sB - \lvert Y \rvert$ 个随机秘密分享并进行随机置换。根据成员零分享的独立性要求，输出分享的秘密独立于任何 $t \le m-1$ 方的联合视图。此外，洗牌功能确保共谋方无法获知置换顺序，因此模拟视图与真实执行不可区分。完整的安全性证明如下：

设 $\textbf{P}_{\mathcal{A}}$ 为被控方集合。在 MPSO 协议中，模拟器接收 $P_c \in \textbf{P}_{\mathcal{A}}$ 的输入 $X_c$；若 $P_1 \in \textbf{P}_{\mathcal{A}}$，则接收结果 $Y$。$P_c$ 的视图包含输入、来自 $\FuncbMZS^{Q'_i}$ 的分享 $\textbf{s}_{i, c}$、来自 $\FuncMS$ 的洗牌份额 $\textbf{u}_{c}'$，以及重构消息 $\textbf{u}_j'$。

设 $\textbf{Q}_{\mathcal{A}}$ 为未涉及诚实方的子公式集合，$\textbf{Q}_{\mathcal{H}}$ 为涉及至少一个诚实方的集合。模拟器按如下方式模拟：
\begin{itemize}
\item 对于 $Q_h \in \textbf{Q}_{\mathcal{H}}$，模拟来自 $\FuncbMZS^{Q'_h}$ 的均匀随机秘密分享。
\item \textbf{情况 $P_1 \notin \textbf{P}_{\mathcal{A}}$：} 从 $\FuncMS$ 中为 $P_c$ 采样均匀随机分享 $\textbf{u}_{c}'$。
\item \textbf{情况 $P_1 \in \textbf{P}_{\mathcal{A}}$：} 腐化方诚实调用 $\textbf{Q}_{\mathcal{A}}$ 相关协议后，持有秘密集 $Y_{\mathcal{A}}$（拼接全零串）及随机秘密集 $R_{\mathcal{A}}$。设 $Y_{\mathcal{H}} = Y \setminus Y_{\mathcal{A}}$，模拟器采样补全所需的随机值集 $R_{\mathcal{H}}$。最后随机置换并重新分享 $Y \cup R_{\mathcal{H}} \cup R_{\mathcal{A}}$。
\end{itemize}

在 $P_1 \notin \textbf{P}_{\mathcal{A}}$ 情况下，$P_c$ 收到的分享与真实执行中的分布（由诚实方保证的独立均匀分布）一致。在 $P_1 \in \textbf{P}_{\mathcal{A}}$ 情况下，利用批量成员零分享的独立性要求以及洗牌协议的理想特性，可以证明真实视图中涉及诚实方的分享也是均匀分布且独立的，因此模拟视图与真实执行计算不可区分。MPSO-card 及 Circuit-MPSO 的安全性证明同理，区别仅在于模拟器在 $P_1$ 腐化时使用 0 代替具体元素。
\end{trivlist}
